# Rename the Planet

A tiny deterministic Node program for the make.fun "Rename the Planet" bounty. It writes a single line to `/output/entry.txt`: a funny new name for Venus, plus the why, in the same breath — 465°C and crushingly suffocating, yet every probe we send still slides into its DMs.

Run it with `node main.ts`. No dependencies, no network, no randomness — the same bytes every run.
